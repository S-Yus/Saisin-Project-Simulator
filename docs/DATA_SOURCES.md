## 9. 更新手順
1. 公式URLから再取得したファイルを `market-data/raw/` に置き、`catalog.json` の `sha256`・`retrieved_at`・`meta.version` を更新する（取得できない場合にアクセス制限を回避しない）。
2. `npm run build-data` で検証し、`market-data/build/dataset.json` を生成する。エラーがあれば生成されない。
3. 管理画面で取込 → 許諾の確認記録 → 固定。データが変わると内容ハッシュが変わり、動作確認は自動で解除される。
